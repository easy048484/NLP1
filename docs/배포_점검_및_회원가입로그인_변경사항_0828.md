## 2. `feat/auth` 브랜치 변경사항 정리 (커밋 전, working tree 상태)

### 신규 — 회원가입/로그인 (`apps/api/auth/`)
- `users` 테이블 (id, email, password_hash, name, created_at, updated_at)
- 비밀번호: PBKDF2-HMAC-SHA256 해싱 (stdlib, C 확장 없음, OWASP 권고 반복 60만회)
- 토큰: JWT(HS256), 14일 만료, `JWT_SECRET` 환경변수로 서명
- 엔드포인트: `POST /auth/register`, `POST /auth/login`, `GET /auth/me`
- 로그인 실패 시 "이메일 없음"과 "비밀번호 틀림"을 구분하지 않음 (계정 존재 여부 비노출)

### 변경 — family_graph 소유권 연결
- `family_graphs.user_id` 외래키 추가 (nullable — 익명 그래프는 NULL 유지)
- 로그인 사용자가 만든 그래프는 본인만 조회/수정 가능 (타인 접근 시 404로 존재 자체를 숨김)
- 비로그인으로 만든 그래프는 기존처럼 id(추측 불가 32자리 hex)를 아는 사람이면 접근 가능한 capability-token 모델 유지
- `POST /family-graph/{id}/claim` — 익명 그래프를 로그인 후 계정에 연결
- `GET /family-graph/mine` — 내 계정에 연결된 그래프 조회

### 신규 — family_graph 구성원 수정/삭제
- `PATCH /family-graph/{id}/members/{member_id}` — 보낸 필드만 부분 수정
- `DELETE /family-graph/{id}/members/{member_id}`
- (이전엔 구성원 추가만 가능하고 수정/삭제가 없었던 격차 항목 중 하나 해소)

### 변경 — 프론트엔드 (`apps/web`)
