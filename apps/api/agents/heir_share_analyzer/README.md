# 상속분·유류분 1차 위험 점검 에이전트

이 에이전트는 법률 판단을 대신하지 않는다. 가족관계와 사용자가 확인한
재산·채무를 바탕으로 다음 정보만 코드로 계산한다.

- 법정상속분
- 기본 유류분 예상액
- 유언장상 예정 취득액과의 단순 차이
- 전문가 검토가 필요한 위험 신호
- 변호사 상담에 전달할 사실관계 요약과 준비자료 목록

## 지원 범위

- 배우자와 생존 자녀
- 생존 자녀만 있는 경우
- 배우자와 부모
- 부모만 있는 경우
- 배우자 단독상속
- 형제자매만 있는 경우(현행법상 유류분 비율 0으로 표시)

## 자동 계산을 중단하거나 전문가 검토로 전환하는 경우

- 대습상속, 조부모 상속처럼 현재 family_graph만으로 지분을 확정할 수 없는 경우
- 상속포기·상속결격·상속권 상실
- 특별수익·기여분
- 과거 증여의 산입 범위가 불명확한 경우
- 재산가액 다툼, 해외 재산 등

결과 문구는 `유류분 침해 확정` 또는 `청구 가능 금액`이라고 표현하지 않는다.
항상 `단순 부족 예상액`과 `전문가 검토 필요`로 표시한다.

규칙 버전은 `civil_act_2026-03-17`이며, 상속개시일이 그보다 앞선 경우에는
당시 법령 적용을 전문가가 확인하도록 한다.
