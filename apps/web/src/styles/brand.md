# EZ-NEXT 브랜드 가이드 (프론트엔드)

> **EZ-NEXT** — "가족의 다음을 쉽게 설계하다"

## 네이밍

- 영문: **EZ-NEXT** (모두 대문자, 자간 좁게). `EZ`(쉽게) + `NEXT`(다음).
- 국문 병기: **이지넥스트**
- 태그라인: **가족의 다음을 쉽게 설계하다**
- 폐기된 이전 명칭: "헤리온/HERION", "가문/Family Ledger", "가족 자산 준비" — 코드에서 발견 시 EZ-NEXT로 교체.

## 심볼

이어지는 두 개의 전진 화살표(`>>`) = "다음 단계로". 앞 화살표는 아이보리(사용자가 밟은 길),
뒤 화살표는 골드(다음에 할 일). 가족 그래프에서 노드→노드로 이어지는 은유와 연결된다.
`public/favicon.svg` 참조.

## 색 (styles/tokens.css가 단일 출처)

| 역할 | 라이트 | 용도 |
|---|---|---|
| 배경 | `#FAF8F4` | 페이지 바탕 (웜 뉴트럴) |
| 카드 | `#FFFFFF` | 표면 |
| 잉크 | `#1C1E24` | 본문 |
| 뮤티드 | `#5E5A52` | 보조 텍스트 (대비 ≈7:1) |
| 프라이머리 | `#1B2A4A` (네이비) | CTA, 헤더, 통장형 카드 |
| 포인트 | `#B0893D` (골드) | 아이브로·헤어라인·강조 (면적 5% 미만으로 절제) |

신호등 4색: `--state-ok/bad/warn/info`. **색만으로 의미를 전달하지 않는다** — 항상 아이콘 + 텍스트 병기.

에이전트 5색: heir=blue, share=teal, estate=purple, tax=green, asset=amber.

## 타이포

- 헤딩·금액·워드마크: **Noto Serif KR** (500/600/700). `--font-serif`.
- 본문·UI·버튼: **Pretendard** v1.3.9. `--font-sans`.
- 아이브로/키커: 11px, `letter-spacing: 0.14em`, 대문자, 골드.
- 골드 헤어라인(`.gold-rule`): 워드마크·섹션 제목 아래 36×1px.

## 형태

- 기본 라운드 **8px** (`--radius-md`). 카드 8px, 칩/버튼 8px, pill은 999px.
- 결과 카드: 골드 좌측보더 3px + `radius: 0 8px 8px 0`.
- 클릭 타깃 최소 48px (`--control-min`).

## 톤 & 보이스

- 시니어·비전문가 기준: **의문형 라벨 금지** ("필요 서류가 궁금하세요?" → "필요 서류 보기").
- 한 화면 한 질문. 요약 → 상세 계층. 판례는 기본 접힘.
- 사후 축: 차분하게, 독촉·진행률 강조 지양. "천천히 하셔도 됩니다."
- 법률/세무 단정 금지: "무효입니다" → "무효로 판단한 판례가 있습니다". 주어는 법원/판례.
- 명령형 지양: "하세요" → "권합니다".
